# User manual

How to change the portfolio yourself, without Claude. Each task has its own guide.

| Task | Guide |
|---|---|
| Add a new article, or edit an existing one | [add-or-edit-article.md](add-or-edit-article.md) |

More guides will be added here, one file per task.

## Good to know

- Everything you change goes live by itself about **2 minutes** after you commit. You don't need to run anything.
- The live site is https://jibinp.github.io/portfolio/
- Progress is shown on GitHub under the **Actions** tab: a green tick means live, a red cross means the change didn't go live (see the troubleshooting part of each guide).
- This repo is public. Never put phone numbers, home addresses, client names or passwords in any file.
