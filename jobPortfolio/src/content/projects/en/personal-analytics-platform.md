## What it is

A personal web app of about 50 pages that brings my own data into dashboards: finance, health and career progress.

## How it's built

- **Front end:** multi-page HTML, CSS and JavaScript.
- **Database:** PostgreSQL on Supabase, with its own schemas and SQL functions for data entry.
- **Automation:** scheduled TypeScript edge functions that fetch public data, such as currency exchange rates.
- **Hosting:** deployed on Netlify and Vercel.
